# City-AQI-Power-BI
City Project

A Power BI dashboard designed to explore and visualize key metrics of urban environments. This repository contains the .pbix file and accompanying documentation to help you get started.

🚀 Getting Started

These instructions will help you set up and run the City Project dashboard on your local machine.

Prerequisites

Microsoft Power BI Desktop (latest version recommended)

Windows operating system (Power BI Desktop is only available on Windows)

Installation

Clone the repository:

git clone https://github.com/<your-username>/city-project.git
cd city-project

Open the Power BI file:

Double-click city project.pbix to launch it in Power BI Desktop.

📊 Usage

Navigate through the report pages using the tabs at the bottom.

Interact with slicers and filters on the right pane to refine your analysis.

Hover over visuals to see tooltips with additional context.

📈 Key Features & Visualizations

Overview Page: High-level KPIs such as population density, average commute time, and housing affordability.

Demographics: Breakdown of age groups, income brackets, and education levels.

Infrastructure: Interactive map displaying roads, public transport routes, and points of interest.

Trend Analysis: Line and bar charts showing changes over time (e.g., population growth, traffic volume).

Feel free to add or remove sections based on what your .pbix file contains.

💡 Customization

To connect to a different data source, go to Home > Transform data > Data source settings.

Modify or create new measures in the Modeling tab.

Adjust report themes under View > Themes.
